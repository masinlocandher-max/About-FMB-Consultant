This directory contains the full revised manuscript used for the About FMB Consultant project.

Read the manuscript files in numeric order from `01.md` through `14.md`. Concatenating those files with exactly one newline between files reconstructs the complete Markdown manuscript.

The obsolete **No One Knows the Formula** expanded edition is not canonical for this project and was not used as the manuscript source here.
